# ゴロゴロPay — Personas

**Document Version**: 1.0
**Created**: 2026-05-07
**Scope**: MVP

本ドキュメントはメインペルソナ「ゴロゴロ太郎」を1人に絞り、**ダメ化フェーズ1（快感）→ フェーズ2（依存）→ フェーズ3（退化）** の感情変遷を深く描写する。

> **Note**: 本ドキュメント内の識別子「ゴロゴロ太郎」と、`requirements.md` §2.2.1 の仮名「佐藤陽介」は **同一人物** を指す。User Stories での参照は「ゴロゴロ太郎」、Requirements §2 での提示用には「佐藤陽介」を使い分けている。基本属性（27 歳・Web ディレクター・年収 550 万円・一人暮らし）は両者で完全に一致。

## Persona 1: ゴロゴロ太郎（メインペルソナ）

### 基本属性

| 項目 | 内容 |
|---|---|
| 名前 | ゴロゴロ太郎 |
| 年齢 | 27歳 |
| 性別 | 男性 |
| 居住地 | 東京都世田谷区、賃貸1LDK（実家は神奈川県） |
| 職業 | 都内IT企業のWebディレクター（新卒5年目） |
| 年収 | 約550万円 |
| 月の自由に使える額 | 約8万円 |
| 婚姻 | 独身、恋人なし |
| 家族構成 | 実家に父母（元気）、妹（大学生） |

### 背景ストーリー

大学卒業後、都内企業に就職。最初の2年は実家から通勤していたが、通勤時間と親のお小言に疲れて3年前に一人暮らしを開始。
実家では母が全てをやってくれていた — 朝食・弁当・洗濯・掃除・役所の書類・宅配便の受け取り・病院の予約。
一人暮らし開始直後、「これ全部自分でやるのか…」と途方に暮れる。

この3年間、太郎の生活は徐々に荒廃してきた：

- **1年目**: 最初の半年は頑張って自炊したが、残業が続くと続かなくなり、コンビニ食が定着
- **2年目**: 部屋の掃除が月1回に減り、洗濯物がベッドの半分を占領。区役所からの住民税通知を3ヶ月放置
- **3年目**: 配達業者の時間指定を忘れて不在、再配達を繰り返す。健康診断の予約を先延ばし

給料はそこそこ上がってきた。お金は余裕がある。**でも、何にどう使えば楽になるか考えるのが、そもそも面倒**。
Amazon は使うが、「何を買えば良いか検索して選ぶ」時点で疲れる。デリバリーアプリも入れているが、店を選ぶのが面倒で結局コンビニに行く。

太郎は、**考えることが嫌い**。選ぶことも嫌い。入力することも嫌い。
ただ「楽になりたい」。

### 価値観・行動特性

- **認知エネルギーが希少**: 仕事で頭を使うので、プライベートでは「考えない」ことが快感
- **金銭感覚**: 「1,000円で面倒が消えるなら安い」と思える派。コスパより労力コスパ
- **衝動性**: 瞬間的な「楽したい」欲求に抗えない
- **自己肯定感**: 中程度に低下中（「自分、ダメになってきてるな…」と自覚あり、でも止められない）
- **孤独耐性**: 高い（一人が苦ではない、むしろ他人と関わらない選択肢を好む）
- **スマホ依存**: 高い（1日6〜8時間、SNS / YouTube / ソシャゲ）
- **衝動買い傾向**: 中（Amazon で深夜に謎の物を買う癖）

### 目標・欲求

| 欲求 | 優先度 |
|---|---|
| 生活の「面倒」を最小化したい | ★★★★★ |
| 何かを「選ぶ・考える」工程を回避したい | ★★★★★ |
| 楽になる罪悪感を、お金を払うことで相殺したい | ★★★★ |
| 失敗を避けたい（自分で判断して失敗するよりAIに任せたい） | ★★★★ |
| 自己肯定感を保ちたい（でも自力では保てない） | ★★★ |
| 貯金したい | ★★ |
| 健康になりたい | ★★ |

### 痛み（Pain Points）

- デリバリーアプリを開いても「どの店にしよう」で5分迷って結局諦める
- 部屋が汚いのは分かっているが、掃除業者を探す・比較する・予約する工程で脱落
- 役所手続きは書類を取り寄せる段階で詰む
- 「やるべきこと」のToDoが溜まり続け、週末は後悔で終わる
- 買い物・食事・健康管理の全ての選択で**決定疲れ**を起こしている

### ゴール

本人が言語化できるゴール: 「とにかく楽したい」  
本人が言語化できないが本質的なゴール: 「**自分で決める責任を誰かに委ねたい**」

## ダメ化フェーズ別の感情変遷

### フェーズ1: ボタンを押すだけ（快感の発見）

**期間**: ゴロゴロPay 使用開始 〜 初月

**きっかけ**: 金融グループのニュースで「ゴロゴロPay」を知り、「月3万円でめんどうが消える」に惹かれてインストール。

**行動**:
- ダメ予算を月 30,000円 に設定
- 空腹時、試しに「ご飯めんどくさい」ボタンを押す
- **3秒後**、「注文完了: カレーハウスCoCo壱番屋 ¥1,200 残りダメ予算 ¥28,800」の表示

**感情変遷**:
- 押す前: 「本当に動くのか？ 金融アプリは堅そうだし…」（半信半疑）
- 押した瞬間: 「…え、もう終わったの？」（驚き）
- 30分後にカレーが届く: 「うそだろ、何も考えず食えた」（快感）
- 深夜、今度は「部屋掃除めんどくさい」を押してみる（※ MVP では未実装だが将来）
- 翌朝: 「これ、生活が変わるのでは…？」（高揚）

**この時期の太郎の内的独白**:
> 「あ、これやばい。考えなくていい。選ばなくていい。ボタンを押すだけで全部終わる。  
>  これ、俺が今まで人生で感じた一番の快感かもしれない。1,200円でこれが買えるなら、安いでしょ」

**体験の核**: **決定疲れからの解放**

---

### フェーズ2: ボタンすら不要（依存の深化）

**期間**: 使用開始 2ヶ月目 〜 4ヶ月目

**きっかけ**: 太郎の利用履歴（平日19時にご飯、週末午後に掃除、月末に役所関連）がデータ蓄積される。アプリを開いた瞬間、サジェストカードが出る。

**行動**:
- 平日19時、アプリを開く
- 画面の一番上に **「そろそろご飯めんどくさいですよね？」** カード
- 「カレー行っときます？（CoCo壱新宿店 ¥1,200）」の横に1タップの「YES」ボタン
- 太郎は思考せず、条件反射で「YES」を押す

**感情変遷**:
- 初めてサジェストを見た時: 「俺のこと分かってる…」（ちょっと怖い、でも嬉しい）
- 2週間目: サジェスト通りに注文するのが当たり前になる。能動的に「何が欲しい」と考える機会が消える
- 1ヶ月目: アプリを開く前から「何が出るだろう」と期待するようになる（パチンコ化）
- 2ヶ月目: サジェストが出ない日（履歴が少ない日）は **「不安」** を感じるようになる

**この時期の太郎の内的独白**:
> 「最近、自分で『何食べよう』って考えた記憶がない。でも楽。  
>  アプリの方が俺より俺のこと分かってる気がする。任せとけばいい」

**体験の核**: **自己決定権の段階的放棄**

**危険信号**:
- Amazon アプリや他のデリバリーアプリを開く回数が激減（選ぶ必要がないから）
- 友達に「今日何食べる？」と聞かれても「任せる」としか答えられなくなる
- 「何がしたい？」という質問自体が苦痛になる

---

### フェーズ3: 完全に人がダメになる（退化と依存ループ）

**期間**: 使用開始 5ヶ月目 以降

**きっかけ**: ある月の 25 日、太郎は残高 0 円に到達する。

**行動**:
- 残高 0 円で「ご飯めんどくさい」ボタンが押せない
- 画面に **「今月、ダメになれません」** と表示
- 画面下部に「今月のダメ化サマリ: 面倒回数 47 回、消化額 ¥30,000」の表示
- そして、**「翌月予算を増額しますか？（推奨: ¥50,000）」** モーダル

**感情変遷**:
- 残高 0 を見た瞬間: 「え、もう終わり？今月まだ5日あるのに」（絶望）
- 代替策を考えようとする: 「じゃあ自分で…何を？」 → **何も思い浮かばない**
- 今月のダメ化サマリを見る: 「47回も面倒を消したのか…」（空虚な優越感）
- 増額モーダルを見る: **迷わず OK を押す**

**この時期の太郎の内的独白**:
> 「今月ダメになれない… 5日間どうすればいいんだ。  
>  え、自分で何かやるの？ 無理だろ。ボタンなしで何をどうすれば…（思考停止）  
>  来月から5万にするか。月1,600円増えるだけだし。安いよ安い」

**体験の核**: **依存の自覚と、それでも止められないループ**

**退化の証拠**:
- 3日連続でボタンなし生活を試みた結果、コンビニ弁当で過ごし、部屋はさらに荒れた
- 自分で「選ぶ」ことが億劫すぎて、ボタンなしでは何も決められない
- 来月の増額後、**さらに依存が深まる**ことを薄々理解している
- でも止められない。戻れない

**最終的な太郎の独白**:
> 「ゴロゴロPay がない生活に戻れない。俺は戻りたくない。  
>  月5万？ 6万？ いくらでも払うよ。もう自分で決めたくないんだ」

## ペルソナの物語的意義

太郎の物語は、idea.md の中核テーゼ —

> **ボタン1つで人生が回る → ボタンすら不要になる → 完全に人がダメになる**

を一人のペルソナの3フェーズの感情変遷として具現化する。

本プロジェクトの全ユーザストーリーは、太郎のこの物語のいずれかのフェーズに属する形で設計される。**ストーリー1本1本が、太郎を一段ずつダメにする**。これが本プロジェクトのストーリー設計哲学である。
