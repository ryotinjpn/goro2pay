# 開発予定のユースケースおよびアプリの構想

## 金融業との親和性
- キャッシングの「必要なときに即使える」利便性を、生活の面倒ごとに拡張
- 即時決済UX・予算管理・利用履歴など、金融のドメイン知識を直接転用できる

## サービス名
ゴロゴロPay

## コンセプト
「めんどくさい」を押すだけで、お金の力で全部解決してくれるアプリ。
ボタン1つで生活のあらゆる面倒を即時キャッシュで解消する。

## ペルソナ
一人暮らしの社会人。実家では親が全部やってくれていたが、一人暮らしになり家事・自炊・各種手続き・体調管理を全部自分でやる羽目に。お金はそこそこあるが、何にどう使えば楽になるか考えるのすら面倒。

## 仕組み
1. 毎月の「ダメになる予算」を設定（例：月3万円）
2. アプリを開くと画面中央にでっかいボタンが1つだけ
3. ボタンを押す →「何がめんどくさい？」と聞かれる（音声でもOK）
4. 答える → 予算から即時引き落としで最適な代行サービスを自動手配
5. 完了

## ユーザー体験の例

```
ユーザー：「ご飯つくるのめんどくさい...」
アプリ  ：UberEats注文完了（1,200円引落） 残りダメ予算：28,800円

ユーザー：「部屋の掃除めんどくさい...」
アプリ  ：清掃業者手配完了（5,000円引落） 残りダメ予算：23,800円

ユーザー：「役所の手続きめんどくさい...」
アプリ  ：代行サービス予約完了（3,000円引落） 残りダメ予算：20,800円
```

## 人をダメにするポイント

### フェーズ1：ボタンを押すだけ
- 面倒なことがボタン1つで即消える快感に慣れる
- 自分で動く理由がなくなる

### フェーズ2：ボタンすら不要になる
- 使い続けると行動パターンを学習
- ボタンすら押さなくても「そろそろ飯めんどくさいですよね？」と先回り
- 最終的にアプリを開く必要すらなくなる
- ボタンを押すことすらめんどくさくなる

### フェーズ3：完全に人がダメになる
- 予算が尽きた月末、何もできない自分に気づく
- 翌月は予算を増やしてしまう
- 自分で動く能力が退化し、ボタンなしでは生活できなくなる

---

**ボタン1つで人生が回る → ボタンすら不要になる → 完全に人がダメになる**
