AI-DLC プロセス

5 Unit に分解し、全フェーズを実践

Auth  /  Budget  /  Order  /  Suggest  /  Metrics

各 Unit を独立 PR で管理。
ドキュメント生成から実装まで一気通貫。

工夫①　ペルソナと設計の1対1対応

陽介の3フェーズを先に深く設計した上で、
各Unit・各画面・各セリフがどのフェーズに対応するかを明確に紐付け。

「なぜこのUI、なぜこのセリフか」が
全て陽介の感情変遷から導かれているため、設計の軸がぶれない。

工夫②　デザインシステムを横串成果物として独立

全画面共通の「デザイン哲学」を１つのファイルに一本化。

  • フォント / カラートークン
  • セリフシステム
  • 状態モデル

「いつでもやり直せる」という土台を構築。

工夫③　NFRに「ダメ化UX」を独自定義

一般的なNFRは「3秒以内に返す」「不正アクセスを防ぐ」
といった性能・セキュリティ要件。

私たちは「ダメ化UX」を非機能要件として定義。

「UI」「セリフ」「サジェスト機能」——これら全てが
「意思決定」をAIへ委譲するよう促す体験。それを要件レベルに。
